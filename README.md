# Jinks

**Jinks** is the AI developer that works inside your own folders — real files,
a real terminal, and a live preview, right on your machine.

- Desktop app for **Windows, macOS and Linux**
- Bind any folder as a **workspace**, keep separate **chats** per workspace
- **Permission modes** keep you in control: ask before every change, auto file
  edits, full access, or read-only planning
- Sign in once with a one-time code — no configuration

## Download

Grab the installer for your OS from the
[latest release](https://github.com/SirBNL/jinks/releases/latest) or from
[jinks.metora.ir/download](https://jinks.metora.ir/download) (auto-detects your platform).

| Platform | File |
|---|---|
| Windows 10/11 (64-bit) | `Jinks-Setup-1.1.0.exe` |
| macOS Apple Silicon | `Jinks-1.1.0-arm64-mac.zip` |
| macOS Intel | `Jinks-1.1.0-mac.zip` |
| Linux | `Jinks-1.1.0.AppImage` |

**macOS first launch:** unzip, drag Jinks into Applications, then right-click
the app and choose *Open* once. **Linux:** `chmod +x Jinks-1.1.0.AppImage` and run.

Built by the **Metora team** — running at [jinks.metora.ir](https://jinks.metora.ir).
